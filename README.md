# 🚀 Medels-Creaty

A robust full-stack Flask web application engineered for community interaction, secure user authentication, and profile management. Built with a clean modular architecture and optimized for seamless cloud deployment.

---

## 🛠️ Tech Stack

* **Core:** Python, Flask, Flask-SQLAlchemy, SQLite
* **Frontend:** HTML5, CSS3, Jinja2 Templates
* **Server & Deployment:** Gunicorn, Render
* **Version Control:** Git & GitHub

---

## ✨ Key Features

* **Secure Authentication:** Implements robust sign-up, login, OTP verification, and password reset flows[cite: 2, 3].
* **Community Engagement:** Dynamic platform for creating, sharing, and tracking community posts and user activity[cite: 2].
* **Profile Management:** Comprehensive user directory, profile viewing, and editing capabilities[cite: 2, 3].
* **Modular Architecture:** Clean multi-page structure scaling across 12+ responsive HTML templates[cite: 3].

## 🎯 Why Creaty? (Core Purpose)

**Creaty** is a dedicated social and collaboration platform custom-built for creative and curious minds. The core vision behind making Creaty is to bridge the gap for individuals who notice creative problems and innovative concepts around the world, but lack a centralized space to discuss or solve them. 

Creaty empowers users to:
* **Discover Real Problems:** Read through problem posts and challenges shared by others from different corners.
* **Collaborate & Solve:** Share meaningful solutions, spark discussions, and contribute to innovative problem-solving.
* **Learn & Grow:** Explore new concepts and insights introduced by other users through their solutions, building a community driven by creativity and curiosity.
